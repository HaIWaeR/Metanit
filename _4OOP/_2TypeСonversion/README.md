# Преобразованию типов в C#

## 1. Иерархия классов
```c#
class Animal { }          // Базовый класс (родитель)
class Dog : Animal { }    // Производный класс (наследник)
class Cat : Animal { }    // Производный класс (наследник)
```

# Восходящее преобразование (Upcasting)

От наследника к родителю.
Всегда безопасно, выполняется автоматически (неявно).

```c#
Dog dog = new Dog();
Animal animal = dog;  // Неявное преобразование
```
# Нисходящее преобразование (Downcasting)

От родителя к наследнику.
Требует явной проверки, так как не каждый объект родителя является наследником.

```c#
Animal animal = new Dog(); // Опасно Может быть исключение:
Dog dog = (Dog)animal;
```

Безопасные способы нисходящего преобразования

## Оператор is
Проверяет тип и преобразует в одну строку.

```c#
if (animal is Dog dog)
{
    // dog доступен только здесь
    Console.WriteLine("Это собака!");
}
```

## Оператор as

Пытается преобразовать, при ошибке возвращает null.

```c#
Dog? dog = animal as Dog;
if (dog != null)
{
    Console.WriteLine("Это собака!");
}
```

# Определение реального типа

Метод GetType() показывает реальный тип объекта в памяти.

```c#
Animal animal = new Dog();
Console.WriteLine(animal.GetType().Name); // "Dog"
```

# Порядок проверок через is

Проверяй от конкретного к общему (от наследников к базовому классу).

```c#
if (obj is Dog) { ... }
else if (obj is Cat) { ... }
else if (obj is Animal) { ... }  // В конце
```
