# Обработка исключений.
Исключение - это ошибка, возникающая во время выполнения программы (деление на ноль, потеря сети, неверный формат данных)

## Конструкция try catchfinally
```csharp
try
{
    // Код, в котором может возникнуть ошибка
}
catch
{
    // Обработка ошибки
}
finally
{
    // Код, выполняемый в любом случае
}
```

Порядок выполнения:
- Выполняется код в блоке try
- Если ошибок нет - выполняется finally
- Если ошибка есть - выполнение останавливается, ищется подходящий catch
- После catch выполняется finally
- Если подходящий catch не найден - программа аварийно завершается

Пример:
```csharp
try
{
    int x = 5;
    int y = x / 0;
}
catch
{
    Console.WriteLine("Возникло исключение!");
}
finally
{
    Console.WriteLine("Блок finally");
}
```

Вывод:
```text
Возникло исключение!
Блок finally
```

## try + catch (без finally):
```csharp
try
{
    // Опасный код
}
catch
{
    // Обработка ошибки
}
```

## try + finally (без catch):
```csharp
try
{
    // Опасный код
}
finally
{
    // Очистка ресурсов
}
```
